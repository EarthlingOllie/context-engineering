---
name: forge-diff
description: Work through a given set of findings, investigating each and fixing it test-first until resolved idiomatically.
---

For each of a given set of findings:

1. Investigate the validity and shape of the finding
2. Make a fix if necessary practicing /test-driven-development as you go. 
3. Consider the cohesion of fix against the wider diff.
4. Continue until the finding is resolved idiomatically.
